# Café Urainari (裏稲荷) // Rojiura 1.0m

> **도쿄 폭 1m 비유클리드 빗속 골목길과 숨겨진 심야 카페 [우라이나리(裏稲荷)]**
>
> 🌐 **Live Website**: [https://urainari.marsko.art](https://urainari.marsko.art)

비에 젖은 어두운 도쿄의 뒷골목을 1인칭 와이어프레임 뷰로 직접 탐색하며, 바닥 물웅덩이에 반사되는 호박색 네온, 머리 위 전선에 매달린 여우불 전구, 작은 여우 석상의 시선 등 환경 단서를 찾아 숨겨진 심야 카페 [우라이나리]를 찾아가는 텍스트-비주얼 인터랙티브 아트워크입니다.

## Features
- **Procedural 3D Alley Rendering**: HTML5 Canvas 기반의 1인칭 퍼스펙티브 골목 와이어프레임 & 빗물 파티클 시스템
- **Non-Euclidean Spatial Maze**: 6단계 신호 동기화(Signal Sync) 및 방향 단서 생성 알고리즘
- **Procedural Web Audio Engine**: Web Audio API로 실시간 합성되는 빗소리, 발자국 노이즈 필터, 신사 풍경 화음 및 재즈 Fmaj7 도착 코드
- **Responsive & Keyboard Navigation**: 모바일 터치 및 데스크톱 방향키(`←` `↑` `→` / `A` `W` `D`) 완벽 지원
